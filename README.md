# Floki24 design clone (frontend only)

A design-focused Next.js + TypeScript recreation inspired by the public Floki24 storefront. This project uses local mock content and client-side UI state only.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Included

- Responsive homepage layout
- Announcement and shipping bars
- Header, search UI, responsive navigation and mega-menu
- Hero carousel
- Category tiles
- Editorial content section
- Product cards, offer and new-arrival sections
- Mock cart drawer and add-to-cart counter
- Footer and newsletter form interaction

## Important

- No Shopify integration, database, backend, or real checkout.
- Product copy/prices are sample display content and are not connected to Floki24.
- Images are remote Unsplash placeholders. Replace them with reference assets you have permission to use for a closer visual match.
- This is a starting implementation, not a pixel-perfect guarantee. Compare against the reference at the same viewport dimensions and tune spacing, imagery, typography, and section heights.
